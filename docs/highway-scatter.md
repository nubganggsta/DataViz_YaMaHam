# Scatter Plot ราย Geometry ถนน

เปิด dashboard ด้วย `.\run_dashboard.ps1` แล้วดูกราฟถัดจากตาราง TRAMS ใน Overview ก่อนหมวดแผนที่ กราฟใช้ HTML Canvas เช่นเดียวกับกราฟแนวโน้มเดิม โมดูล `highway-scatter.js` ถูกโหลดก่อน `app.js`

ใช้ `DATA.records` ผ่าน `getFilteredRecords()` เดิมทั้งหมด จึงรับปี/ไตรมาส/เดือน ภาค จังหวัด ประเภททางหลวง ยานพาหนะ ความรุนแรง การค้นหา และหมวดกราฟเดิม ไม่มี Global State หรือตัวกรองใหม่ การเลือก Geometry เป็นเพียงการเลือกจุด ไม่เปลี่ยนข้อมูลกราฟอื่น

หนึ่งจุด = หนึ่ง `road_feature_id` ที่มี `road_status=matched` รวมจำนวน DISTINCT `id` และบวก `fatalities` หนึ่งครั้งต่อ ID รองรับ ID ตัวเลขของ DOH และ `drr:...` ของ DRR หากเหตุการณ์เดียวมีหลาย Geometry ขัดกันจะไม่นำเหตุการณ์นั้นมารวม ป้องกันการเลือกเส้นผิด หากไม่มี Geometry ยังแสดงรายละเอียดจุดได้และไม่เลือกเส้นใกล้เคียงแทน

ชื่อถนนและรหัสช่วงอ้างอิงจาก road feature; จังหวัด/ภาคสรุปจากเหตุการณ์ที่ผ่านตัวกรอง หากหลายภาคใช้หมวดสี “หลายภาค” ไม่ระบุ กม. แทนขอบเขตของทั้ง Geometry ด้วย กม. ของเหตุการณ์เพียงหนึ่งรายการ หน่วย Geometry อาจมีความยาวต่างกัน และยอดดิบไม่ใช่อัตราความเสี่ยงหรืออันดับความอันตราย

ชี้จุดเพื่อดู Tooltip คลิกเพื่อเปิดรายละเอียดและไฮไลต์ Geometry ID เดียวกันบนแผนที่ ช่องเลือก Geometry ใช้เปิดจุดที่ซ้อนกันได้ เมื่อเปลี่ยนตัวกรอง รายละเอียดและการเลือกจะอัปเดตตามข้อมูลล่าสุด

ตรวจด้วยข้อมูลจริงรุ่นปัจจุบัน: 3,354 จุด, 67,518 เหตุการณ์ที่จับคู่ได้, ผู้เสียชีวิต 8,458 ราย (เฉพาะ matched subset) ทดสอบยอดรวม การไม่นับซ้ำ การปฏิเสธ ID ขัดแย้ง ตัวกรองปี/ไตรมาส/เดือน/ภาค/จังหวัด/ชนบท การกด Canvas และการไฮไลต์ ID DOH/DRR ผ่าน; JavaScript syntax และ HTML IDs ผ่าน การตรวจภาพจริงใน browser ยังทำไม่ได้เพราะปิดสิทธิ์ Local browser use
