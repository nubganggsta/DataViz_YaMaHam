# DataViz_YaMaHam
ข้อมูลผู้เสียชีวิตจากอุบัติเหตุทางถนน จากระบบบูรณาการข้อมูลการตายจากอุบัติเหตุทางถนน

จากชุดข้อมูลทั้งหมด 3 ชุด ตั้งแต่ ปี 2566 - 2568



1. การวิเคราะห์มิติเวลาและพฤติกรรม (Temporal & Behavioral Patterns)
ช่วงเวลาอันตราย (The Deadly Hours): นำมิติเวลาเสียชีวิต/เกิดเหตุ มาทำ Heatmap (24 ชม. x 7 วัน) เพื่อดูว่าชั่วโมงไหนของวันใดที่มีความเสี่ยงสูงสุด (ส่วนใหญ่มักพบช่วงดึกหลังเที่ยงคืน หรือช่วงเลิกงาน)

ฤดูกาลและเทศกาล (Seasonal / Festival Spikes): เปรียบเทียบสถิติช่วงเทศกาลหลัก (ปีใหม่, สงกรานต์) เทียบกับวันปกติ เพื่อชี้ให้เห็นว่าปัจจัยเรื่องการเดินทางท่องเที่ยว/กลับบ้าน หรือการดื่มเครื่องดื่มแอลกอฮอล์ มีผลอย่างมีนัยสำคัญอย่างไร

วิเคราะห์กลุ่มอายุและเพศ (Demographics Risk Profile): ทำกราฟ Population Pyramid หรือ Bar Chart แยกกลุ่มช่วงอายุ (เช่น วัยรุ่น 15-24 ปี vs วัยทำงาน vs ผู้สูงอายุ) ร่วมกับเพศ เพื่อดูว่า "กลุ่มเสี่ยงหลัก" ของประเทศคือกลุ่มใด
