# Road Accident & Fatality Dashboard (TRAMS)

แดชบอร์ดเชิงพรรณนาสำหรับข้อมูลอุบัติเหตุทางถนนจาก TRAMS พ.ศ. 2566–2568 แยกจำนวนเหตุการณ์ออกจากจำนวนผู้เสียชีวิต และแสดงเหตุการณ์บนแผนที่จากพิกัดต้นทาง ไฟล์ CSV ที่ตรวจจริงมี 71,508 แถว 40 คอลัมน์ (ข้อกำหนดเดิมระบุ 39); จำนวนนี้บันทึกใน metadata ตอนสร้างไฟล์ข้อมูล

หน้าตาใช้พื้นครีม `#F8FAED`, สี charcoal `#181717` ในส่วนเน้น/โหมดมืด, สีแดง/ส้มสำหรับผู้เสียชีวิตและผู้บาดเจ็บ และสีม่วง/น้ำเงิน/ชมพูแยกตามจำนวนหลักทางหลวง แผนที่ใช้ [Esri World Imagery](https://doc.arcgis.com/en/data-appliance/2023/maps/world-imagery.htm) ซ้อนชั้น World Transportation สำหรับชื่อถนนและป้ายแผนที่

## เริ่มใช้งาน

1. สร้างข้อมูลที่หน้าเว็บใช้จาก CSV หลัก:

   ```powershell
   .\build_dashboard_data.ps1
   ```

2. เปิดเซิร์ฟเวอร์ในเครื่อง:

   ```powershell
   .\run_dashboard.ps1
   ```

3. เปิด `http://127.0.0.1:8000`

ต้องใช้ Python ที่มี `pandas` (สคริปต์เลือก Python ที่มากับ Codex ก่อน หากไม่มีจะค้นหา `python` ใน PATH)

## กติกานับและตรวจคุณภาพ

- ไฟล์หลักคือ `dataset/accidents_2023_2025.csv` มี 71,508 แถว และข้อมูลสร้างล่าสุดมี 69,806 ค่า `ACC_CODE` ไม่ซ้ำ
- หนึ่ง `ACC_CODE` นับเป็นหนึ่งเหตุการณ์; เหตุการณ์มีผู้เสียชีวิตเมื่อตัวเลขผู้เสียชีวิตมากกว่า 0
- พบกลุ่ม `ACC_CODE` ซ้ำ 1,641 กลุ่ม โดย 448 กลุ่มมีวันที่/เวลา/จังหวัด/พิกัดหรือยอดผู้เสียชีวิต/บาดเจ็บขัดแย้งกัน กรณีซ้ำเลือกแถวที่มียอดผู้สูญเสียรวมสูงสุดเพื่อไม่บวกซ้ำ แต่ผลรวมยังเป็นค่าชั่วคราวและควรตรวจทานกับเจ้าของข้อมูลก่อนอ้างอิงเป็นสถิติทางการ
- ผลจากกติกานี้: 7,313 เหตุการณ์มีผู้เสียชีวิต และ 8,567 ผู้เสียชีวิต สำหรับข้อมูลที่สร้างในโฟลเดอร์ `data/`
- รายงานข้อมูลผิดปกติและกติกานับอยู่ใน `data/dashboard_data.json` (`quality`, `meta`)
- ข้อมูลที่ไม่มีค่าไม่ถูกเติมค่าในระดับแถว; ยอดรวมรายงานเฉพาะค่าที่มี และจำนวนช่องว่างถูกรายงานไว้ใน quality metrics
- ฟิลด์บาดเจ็บรวมที่ใช้ใน KPI คำนวณจากผู้บาดเจ็บสาหัส + เล็กน้อย; ค่าในต้นทางที่ไม่ตรงกันถูกนับในตัวชี้วัดคุณภาพ
- ข้อมูลแสดงความสัมพันธ์เชิงพรรณนา ไม่ยืนยันเหตุและผล

## ตัวกรองและการวิเคราะห์

- ปี พ.ศ., ภาค, จังหวัด, ประเภทยานพาหนะ, สถานะมีผู้เสียชีวิต และค้นหารหัส/ชื่อสายทาง (ไม่มีตัวกรองหน่วยงาน)
- ตัวกรองส่วนพื้นที่และหมวดพฤติกรรม/สิ่งแวดล้อมส่งผลร่วมถึง KPI, กราฟ, ตาราง, แผนที่ และ CSV ส่งออก
- Heatmap วันในสัปดาห์ × ชั่วโมงเต็ม 24 ชั่วโมง พร้อมยอดรวมรายวันและรายชั่วโมง (ช่องรวมไม่ลงสี)
- Line chart เปรียบเทียบเหตุการณ์ไม่ซ้ำและผู้เสียชีวิตรายปี โดยใช้แกนคนละด้าน
- Scatter plot นับเหตุการณ์แบบ DISTINCT `ACC_CODE` และรวมผู้เสียชีวิตตาม `road_feature_id`; แสดงสีแยกภูมิภาคและเลือกจุดเพื่อไฮไลต์ Geometry บนแผนที่
- กราฟสัดส่วนพาหนะ, Donut หน่วยงาน/ประเภทโครงข่ายตามฟิลด์ต้นทาง, Treemap มูลเหตุและลักษณะเหตุ, และไอคอนสภาพอากาศ
- คลิกหมวดในกราฟเพื่อกรองกราฟกลุ่มพาหนะ/มูลเหตุ/ลักษณะเหตุ/สภาพอากาศร่วมกัน; คลิกจังหวัดในแผนที่เพื่อกรอง dashboard ทุกส่วน
- แผนที่จังหวัดใช้สี choropleth ตามจำนวนเหตุการณ์ภายใต้ตัวกรองปัจจุบัน และซูมอัตโนมัติตามประเทศ/ภาค/จังหวัด
- ส่งออกเหตุการณ์ที่กรองแล้วเป็น CSV

การจัดกลุ่มคำเป็นการ normalize ค่าที่มีคำสำคัญตรงกับกติกาในหน้าเว็บ โดยเก็บหมวดที่ไม่ตรงไว้ตามข้อความต้นทาง หมวด “ประเภทโครงข่ายถนน” ใช้ฟิลด์หน่วยงาน/ผู้รับผิดชอบทางจาก TRAMS เป็นตัวแทน เนื่องจากข้อมูลนี้ไม่มีฟิลด์ประเภทโครงข่ายที่แยกชัดเจน จึงควรตีความตามข้อจำกัดดังกล่าว

## ข้อจำกัดการเชื่อมโยงข้อมูล

- แผนที่แสดงจุดเกิดเหตุจากพิกัด TRAMS; จุดสีแดงคือเหตุการณ์มีผู้เสียชีวิต และสีฟ้าคือเหตุการณ์อื่น
- เส้นถนนจริง 3,083 feature มาจาก GeoPackage กรมทางหลวง พ.ศ. 2568 และขอบเขต 77 จังหวัด/6 ภาคมาจาก [บริการ GIS ของกรมป้องกันและบรรเทาสาธารณภัย](https://gis-portal.disaster.go.th/arcgis/rest/services/MapDX/DPM_TH_Boundary/FeatureServer/1)
- เส้นถนนที่ส่งให้ browser ลดรายละเอียดเพื่อแสดงผล (tolerance ประมาณ 3 เมตร); ไฟล์ GeoPackage ต้นฉบับไม่ถูกแก้
- ตัวกรองถนนระดับจังหวัด/ภาคกำหนดพื้นที่ของแต่ละ feature จากจุดกลางของแนวเส้น; เส้นที่พาดผ่านหลายจังหวัดยังไม่ได้ตัด geometry ตามเส้นเขตจังหวัด
- `dataset/accidents_dashboard_joined.csv` เป็นข้อมูลเชื่อมโยงเดิมเฉพาะบางระเบียนเสียชีวิต; Scatter plot ใช้เพียง 6,621 เหตุการณ์ที่จับคู่ได้กับ 1,566 `road_feature_id` จากชุดนี้เพื่อสาธิตความสัมพันธ์ใน matched subset เท่านั้น จึงไม่แทนข้อมูลอุบัติเหตุทั้งหมดหรือใช้อ้างความเสี่ยงรายช่วงทาง และไม่มีการจัดอันดับช่วงทาง/AADT
- รหัสทางใน GeoPackage บางรายการเติมศูนย์นำหน้า เช่น `0001`; คงรหัสต้นฉบับไว้ แต่ใช้จำนวนหลักหลังตัดศูนย์เติมหน้าสำหรับการจำแนกสี
- ขอบเขตภาคใช้ REGION_6 จากบริการ DDPM; ชื่อจังหวัด “อยุธยา” ถูกปรับเป็น “พระนครศรีอยุธยา” ให้ตรงกับขอบเขต
- ปี 2025/พ.ศ. 2568 อาจยังไม่ครบปีและอาจมีความครอบคลุมต่างจากปีอื่น ควรระวังการเทียบยอดดิบ

## ไฟล์สำคัญ

- `data/build_dashboard_data.py` สร้าง JSON จากข้อมูลต้นทางและตรวจคุณภาพ
- `data/dashboard_data.json` เหตุการณ์ระดับ `ACC_CODE` สำหรับแผนที่และตัวกรอง
- `data/accident_summary.json` สรุปสถิติรายปีสำหรับกราฟ
- `data/roads.json` แนวเส้นทางจริงและข้อมูลรหัสทางที่แปลงจาก GeoPackage
- `data/provinces.geojson` ขอบเขตจังหวัดและคุณลักษณะภูมิภาค
- `dataset/` เก็บไฟล์ต้นทางและข้อมูลอ้างอิง
