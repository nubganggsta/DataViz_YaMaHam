# DataViz_YaMaHam: Thailand Road Safety & Highway GIS Intelligence

ระบบรายงานและวิเคราะห์ข้อมูลสถานการณ์อุบัติเหตุและผู้เสียชีวิตทางถนนของประเทศไทย (TRAMS) ร่วมกับโครงข่ายทางหลวงแผ่นดิน (DOH GeoPackage 2568) พ.ศ. 2566–2568

## แหล่งข้อมูลหลัก (Data Sources)

1. **ข้อมูลอุบัติเหตุบนโครงข่ายทางหลวง (TRAMS)**: กระทรวงคมนาคม (`data/accidents_2023_2025.csv`) รวบรวมเหตุการณ์อุบัติเหตุ 71,508 เหตุการณ์ และเหตุการณ์ที่มีผู้เสียชีวิต 7,601 เหตุการณ์ (ผู้เสียชีวิต 8,884 ราย) พร้อมพิกัดจริง วันเวลาเกิดเหตุ และรหัสสายทาง
2. **ทะเบียนบัญชีสายทางและแนวเส้นทางหลวง (DOH GeoPackage 2568)**: กรมทางหลวง (`data/ข้อมูลทะเบียนบัญชีสายทาง (Road_Cl_Line_2568).gpkg`) โครงข่ายเส้นทางหลวงแผ่นดิน LineString / MultiLineString จริง
3. **ขอบเขตการปกครองและภูมิภาค (ราชบัณฑิตยสภา)**: ขอบเขต 77 จังหวัด และ 6 ภูมิภาค (`data/provinces.geojson`)
4. **สถิติปริมาณจราจรเฉลี่ยต่อวัน (AADT)**: กรมทางหลวง (`data/สถิติปริมาณจราจร.xlsx`)
5. **ปฏิทินวันหยุดราชการ**: (`data/thai_holidays_2566_2568.csv`)

## ความสามารถหลักของระบบ (Features)

### 1. ระบบกรองพื้นที่แบบลำดับชั้นและการซูมแผนที่อัตโนมัติ (Hierarchical Spatial Filtering)
- **ประเทศไทย (ทั่วประเทศ)**: แสดงภาพรวมทั้งประเทศ พร้อมแนวเส้นทางหลวงและพิกัดผู้เสียชีวิตทั้งหมด
- **ระดับภาค**: รองรับ 6 ภูมิภาคตามมาตรฐานราชบัณฑิตยสภา (ภาคเหนือ, ภาคตะวันออกเฉียงเหนือ, ภาคกลาง, ภาคตะวันออก, ภาคตะวันตก, ภาคใต้) โดยแผนที่จะคำนวณ Bounding Box จาก Geometry จริง และซูมพอดีกับขอบเขตภาค พร้อมแสดงเฉพาะแนวทางหลวงและจุดเกิดเหตุในภาคนั้น
- **ระดับจังหวัด**: แสดงเฉพาะจังหวัดที่เลือก พร้อมซูมพอดีกับขอบเขตจังหวัด และกรองสายทางกับจุดเกิดเหตุให้อยู่ในจังหวัดนั้นโดยเฉพาะ
- **ระบบ Breadcrumbs**: แสดงตำแหน่งปัจจุบัน เช่น `ประเทศไทย › ภาคตะวันออกเฉียงเหนือ › ขอนแก่น` และสามารถคลิกเพื่อย้อนกลับระดับได้ทันที
- **การเลือกจังหวัดโดยตรง**: หากผู้ใช้เลือกจังหวัดโดยตรง ระบบจะกำหนดภาคที่เกี่ยวข้องให้อัตโนมัติ

### 2. ตัวกรองและการแยกสีตามจำนวนหลักของเลขทางหลวง (Highway Digit Classification)
จำแนกสายทางตามจำนวนหลักของหมายเลขทางหลวงจริง:
- **ทางหลวงเลข 1 หลัก**: หมายเลข 1 หลัก (เช่น ทล. 1, 2, 4) → **สีม่วง** (`#9333ea`)
- **ทางหลวงเลข 2 หลัก**: หมายเลข 2 หลัก (เช่น ทล. 12, 24, 35) → **สีน้ำเงิน** (`#2563eb`)
- **ทางหลวงเลข 3 หลัก**: หมายเลข 3 หลัก (เช่น ทล. 201, 304) → **สีชมพู** (`#ec4899`)
- **ทางหลวงเลข 4+ หลัก / อื่นๆ**: หมายเลข 4 หลักขึ้นไป หรือสายทางชนบท → **สีเทา** (`#64748b`)
- มี Legend แสดงความหมายของสีอย่างชัดเจนถาวร

### 3. การแสดงผลบนแผนที่ GIS
- เส้นทางหลวงแสดงตามแนวเส้นจริง (LineString / MultiLineString) ไม่ใช่การเชื่อมจุดเอง
- จุดผู้เสียชีวิตแสดงจากพิกัดจริง พร้อมระบบ Marker Clustering
- คลิกเส้นทาง: แสดงหมายเลขทางหลวง, จำนวนหลัก, ชื่อสายทาง, จังหวัด, และจำนวนผู้เสียชีวิตที่จับคู่ได้
- คลิกจุดเหตุการณ์: แสดงรหัสเหตุการณ์, วันเวลา, สถานที่, หมายเลขทางหลวง, จำนวนผู้เสียชีวิต/บาดเจ็บ, พาหนะ, มูลเหตุ, ลักษณะเหตุ, และพิกัดจริง
- มีสถานะ Empty State เมื่อไม่มีข้อมูลในตัวกรอง โดยยังคงขอบเขตพื้นที่ที่เลือกไว้

### 4. สถิติและบทวิเคราะห์ TRAMS
- กราฟแนวโน้มรายเดือนและช่วงเวลาเกิดเหตุ (The Deadly Hours)
- สถิติตามวันในสัปดาห์
- ประเภทยานพาหนะ, ลักษณะการเกิดเหตุ, มูลเหตุสันนิษฐาน, สภาพอากาศ
- ตารางสรุปสถิติรายปี (2566, 2567, 2568)
- 10 ช่วงทางที่มีผู้เสียชีวิตมากที่สุด (ปรับตามตัวกรองพื้นที่และเลขทางหลวง)
- ส่งออกข้อมูลเป็น CSV พร้อม BOM ภาษาไทย

## วิธีการใช้งาน

1. ประมวลผลและสร้างข้อมูล:
   ```powershell
   .\build_dashboard_data.ps1
   ```
2. รันเว็บเซิร์ฟเวอร์ในเครื่อง:
   ```powershell
   .\run_dashboard.ps1
   ```
3. เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8000`
